# PART 1 — Create 4 Additional EBS Volumes
## Step 1: Go to EC2 Volumes
```
AWS Console
   ↓
EC2
   ↓
Volumes
   ↓
Create volume
```

## Create the first volume:

Volume Type → gp3
Size        → 30 GiB
AZ          → ap-south-1a

## Create the second:

Volume Type → gp3
Size        → 10 GiB
AZ          → ap-south-1a

## Create the third:

Volume Type → gp3
Size        → 5 GiB
AZ          → ap-south-1a

## Create the Four:

Volume Type → gp3
Size        → 5 GiB
AZ          → ap-south-1a

## You now have:

- Volume 1 → 30 GB → 1a
- Volume 2 → 10 GB → 1a
- Volume 3 → 5 GB → 1a
- Volume 4 → 5 GB → 1a
